## 2. 架構（單台 VM，無額外常駐資料庫伺服器）

```text
交易所公開行情 ──> Go Collector ──> 當日 SQLite + 事件
                                        │
                              每小時備份 / 每日封存
                                        v
                         Google Drive 私有歷史檔案庫
                                        ^
                            按日期讀取 / 受限暫存
                                        │
電腦/手機 ─ HTTPS ─ 輕量反向代理 ─ Go API / V66 靜態網站
  └─ IndexedDB 快取 + Web Worker + 圖表、策略、匯出
  └─ /monitor 仍維持原本瀏覽器交易所直連與必要中繼
```

建議採單一 Go binary（收集、API、Drive 任務各獨立 context／佇列），一個輕量 TLS 入口；React/Vite/TS 前端離線建置後由 Go 提供靜態檔，不在 512MB VM 跑 Node、Miniflare、D1 或大型編譯。Go SQLite 驅動可比較 pure-Go 與 CGO，擇實測資源較低、可重現建置的一種；不得同時維護兩套正式後端。

## 3. 保留舊經驗，不複製舊限制

- 現有已驗證的 Binance、Coinbase、Kraken、Bitfinex 深度取得方式作參考，尤其 Binance diff 序列與 Kraken grouping、Bitfinex P1/P2。不能因重寫就退化成不完整的單次近端快照。
- 不保存所有原始 WS 訊息。10 秒成交統計為聚合後資料；斷線／延遲／缺值獨立記錄。
- 不保存 ALL4／累積區間／比值等可重算數值。永久儲存來源欄位；前端一次批次計算，對同一版本快取結果。
- 不再採 15 分鐘 gzip chunk + 12 小時 package、手動比對補齊、全域 2 req/s、固定 14 天；這些是舊設計，不必相容舊 API。
- Google Drive 是檔案庫而非直接寫入的 SQLite 磁碟；本日資料必須有本機安全暫存。
- 不再需要 Sites Webhook、Sites D1 同步、本地服務、SSH tunnel 主連線；現有 Sites 不得提前關閉。

## 4. 仍屬工程決策的建議預設

以下是本包為減少跨對話歧義所設定的可測試預設，不宣稱使用者逐項指定。若測試證明有更優解，先回報主控：

- 台灣日期分檔；時間一律 UTC epoch ms。日界線為 UTC+8 00:00。
- 容量採十進位 MB/GB；950MB 開始清理、900MB 目標、1,000MB 硬上限；讀取暫存 100MB 納入 1GB。
- 最終每日封存於日界後至少 2 分鐘、完成最後一筆後進行；實際 grace 需以延遲測試定案，不等待無限期補抓。
- API 10 秒增量輪詢，分頁、有限並行、gzip 傳輸；不先做 WS/SSE。
- 瀏覽器快取桌機 500MB／手機 100MB 軟上限，依 StorageManager 可用容量調低，歷史優先淘汰；不是保證可用配額。
- 公開 HTTPS 首選使用者已有網域（若沒有，可測試可自動續期之 IP 憑證；不擅自買網域）。域名、憑證方式與 Google OAuth 一次授權是部署前需由使用者處理的事項。
- 已封存檔案不可原地修改；若確有歷史修正，建立新 revision、保留前版、API 版本失效重讀。
- 每日上傳完成後 VM 刪除已封存本地檔，僅留索引／事件摘要與必要暫存；Drive 不自動刪正式歷史。

## 5. 最後風險檢查

| 風險 | 設計控制 | 驗收前待確認 |
|---|---|---|
| 512MB 主機記憶體或 CPU burst | 瀏覽器運算、單 Go 服務、有限並行、串流匯出、離線建置 | 實測新增合約流與前端中繼、歷史讀取同時進行 |
| Drive 授權失效／斷網 | 小時快照、重試、明確狀態、容量政策 | 真帳號 OAuth 長期授權與換機還原 |
| 1GB 強制刪除未上傳資料 | 先清可恢復檔，記錄永久缺口、保護活躍資料庫 | 使用者已接受永久缺口風險 |
| 新舊來源時間語意差異 | 保留 `available_at`、legacy 品質／來源，不造假 | 匯入與回測測試 |
| HTTPS 或登入暴露 | TLS、密碼雜湊、session、限流、無密鑰前端 | 端口／匿名／憑證續期測試 |
| 歷史檔查詢慢 | 分日索引、快取、增量傳輸 | 手機與 7/30 天載入測試 |
| 切換造成重複或漏收 | 單 writer、最後封存、保留舊資料及 rollback | 先並行測試再正式切換 |

**不需要再進行產品方向問答。** 尚待確認者為授權、憑證、實測與正式切換等工程前置，不是重新開放已確認規格。
