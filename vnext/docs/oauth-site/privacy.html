隱私權政策

版本日期：2026 年 11 月 13 日

本政策說明 MarketDepth VNext 預定在使用者授權 Google Drive 後如何處理資料。本應用程式為個人研究用途，尚在開發與驗收階段。

存取的資料與權限

應用程式僅要求 https://www.googleapis.com/auth/drive.file。此範圍用於存取應用程式建立或使用者明確授權的特定 Drive 檔案，包括資料夾識別碼、檔案識別碼、名稱、大小、完整性資訊及檔案內容。程式不要求 Gmail、聯絡人、相片或完整 Drive 的存取權。

使用目的

Google Drive 資料僅用於儲存、更新、驗證、讀取及還原公開市場行情的封存檔與相關索引，並提供使用者自己的歷史資料查詢及下載。OAuth 權杖僅用於經授權的 API 請求及更新授權。

儲存與安全

行情封存保存於使用者指定的 Google 帳號；運行服務在專案管理者控制的伺服器保存必要的本機資料庫、快取、封存索引及授權憑證。授權憑證與行情檔案分離，不應包含於公開網站、原始碼或封存檔。傳輸使用 HTTPS；檔案保存與還原會進行完整性核對。正式部署前須完成這些安全措施的驗收。

分享與限制

Google 使用者資料不會出售、不會用於廣告、個人剖析、信用評估或訓練通用人工智慧模型，也不會公開給其他使用者。Google Drive 與受管理的伺服器僅用於提供上述功能。應用程式使用和傳輸 Google API 資料遵守 Google API Services User Data Policy，包括適用的 Limited Use 要求。

保留、刪除與撤銷

歷史資料預設保存在使用者的 Drive，直到使用者自行刪除。伺服器本機資料與快取依容量政策清理；撤銷授權不會自動刪除已存入 Drive 的檔案。使用者可在 Google 帳號的第三方連線 移除本應用程式授權，並在 Drive 刪除相應資料。管理者可在伺服器移除本機授權憑證及相關資料。撤銷後，應用程式將無法繼續使用該授權。

本公開網站

本網站僅包含靜態文字，不設登入、表單、廣告、追蹤程式或 Google API 呼叫。網站託管服務可能依其自身政策處理必要的連線或安全日誌。

聯絡與更新

如有資料處理、刪除或安全疑問，請聯絡 Google OAuth 同意畫面中列出的應用程式支援電子郵件。若資料用途改變，將先更新政策及必要的授權設定。
